# dsc-config-learn-env
Repository containing conda environments for FS courses.
* Mac M*x* (silicon chip M1, M2, or M3) and Win have Numpy downgraded and ipykernel
  * Mac Intel needs to have Numpy downgraded to 1.6.4 and ipykernel installed (waiting on that until more testing of the Mac silicon)
* All three files need to have pandasql
* [Current consumer environments](https://github.com/learn-co-curriculum/dsc-data-science-env-config)
* [Conda environment documentation](https://conda.io/projects/conda/en/latest/user-guide/tasks/manage-environments.html)
